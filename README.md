BlueBank – AI Banking Customer Support

BlueBank is an AI-powered banking customer support web application built using Python, Streamlit, and AutoGen. It uses a keyword-based Main Router to direct customer queries to the appropriate specialist agent.

 Key Features
- Account Services Agent: Account opening, KYC, account maintenance, and fees.
- Card Support Agent: Card activation, declined payments, and lost or blocked cards.
- Transaction Enquiry Agent: Transfer status, pending payments, and refunds.
- Loan Information Agent: Personal loans, home loans, eligibility, and repayment guidance.
- Customer Care: Friendly greetings, thank-you responses, and general assistance.
- Security & Escalation: Guides users with suspicious transactions and payment requests toward appropriate human support.
- User Interface: Professional BlueBank branding, navy and blue styling, sidebar navigation, and interactive chat.

Technology Stack
Python • Streamlit • AutoGen AgentChat • OpenAI API • CSS
